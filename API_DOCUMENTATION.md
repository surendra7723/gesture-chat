# Gesture Chat REST API

## Base URL
http://localhost:8000/api/v1/

## Authentication
Use JWT tokens. Include in header: `Authorization: Bearer <token>`

## Interactive Docs
The interactive Swagger/OpenAPI spec is auto-generated by `drf_yasg` and served dynamically:
- Swagger UI: http://localhost:8000/swagger/
- ReDoc: http://localhost:8000/redoc/

## Key Endpoints

### Authentication
- POST /auth/register/ - Register new user
- POST /auth/login/ - Login and get tokens
- POST /auth/logout/ - Logout and optionally blacklist refresh token
- POST /auth/token/refresh/ - Refresh access token
- GET /auth/user/ - Get current user

### Gestures
- POST /gestures/predict/ - Predict gesture from base64 image
- GET /gestures/history/ - Get user's gesture history

### Chat Rooms
- GET /rooms/ - List user's rooms
- POST /rooms/ - Create new room
- GET /rooms/{id}/ - Get room details
- POST /rooms/{id}/join/ - Join room
- POST /rooms/{id}/leave/ - Leave room
- GET /rooms/{id}/messages/ - Get messages in a room
- DELETE /rooms/{id}/ - Delete a room

### Messages
- GET /messages/ - List messages (supports `room_id` query parameter)
- POST /messages/ - Create message
- DELETE /messages/{id}/ - Delete a message

### Profiles
- GET /profiles/ - List current user's profiles
- POST /profiles/ - Create a profile
- GET /profiles/{id}/ - Get profile details
- PUT /profiles/{id}/ - Update profile
- PATCH /profiles/{id}/ - Partially update profile
- DELETE /profiles/{id}/ - Delete a profile
- GET /profiles/me/ - Get or update current user's profile
- PUT /profiles/me/ - Update current user's profile
- PATCH /profiles/me/ - Partially update current user's profile

## Query Parameters

### GET /messages/
- `room_id` (integer) — Filter messages by room ID.

## Example

```bash
# Login
curl -X POST http://localhost:8000/api/v1/auth/login/ \
  -H "Content-Type: application/json" \
  -d '{"username": "user", "password": "pass"}'

# Use token
curl -X GET http://localhost:8000/api/v1/auth/user/ \
  -H "Authorization: Bearer <token>"
```
